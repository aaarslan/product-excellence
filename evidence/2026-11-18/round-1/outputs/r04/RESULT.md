# Recommendation: a booked borrowing desk

Run a four-week trial through existing WhatsApp, with one reservation owner, a private register, and **up to four one-week loans**. Test whether residents can receive a complete, usable item on an agreed date and return it within the available volunteer time.

## What a resident experiences

A short group notice gives the four session dates, request deadline, available items and duty volunteer. Residents privately message that volunteer with the item, intended use date, and whether both collection and return appointments work. They need no new app.

For example, someone wants the carpet cleaner before a Sunday visit. By Friday they receive a definite answer for Saturday, based on an item already checked and held in the cupboard:

“Carpet cleaner reserved: collect Saturday 10:10; return next Saturday 10:10. Please reply to accept both appointments.”

The confirmation includes the contents and pack-up checklist. At collection, volunteer and resident check the kit together, record its condition and confirm the return date. A private reminder precedes the return appointment; the volunteer checks contents and condition again before closing the loan.

If unavailable, the resident gets an explicit no for their requested date and can ask to be contacted later. A returned item with a missing cable stays unavailable. A late return triggers one private follow-up and an agreed appointment at the next published session. Nobody receives a promise dependent on another resident returning something.

## What we operate

Use the four existing Saturday 10:00–10:45 sessions:

- **Week 1:** Check and label up to four requested items, prioritising the carpet cleaner and projector where requested. Publish only items verified complete and usable.
- **Week 2:** Issue those items in booked ten-minute appointments, maximum four. Reduce capacity if an item needs a longer handover.
- **Week 3:** Receive and inspect returns.
- **Week 4:** Handle late or incomplete returns and review the trial. No new loans.

This deliberately leaves a recovery week. Thursday 17:30–18:15 is a replacement only when Saturday is unavailable; publish that substitution before accepting bookings. It is not an additional opening.

Budget each week: 45 minutes on site, 30 minutes across three scheduled WhatsApp checks, and 15 minutes for exceptions. Pause new commitments when that allowance is exhausted. One volunteer answers reservations; the backup uses the same register when taking over. Keep item status, borrower contact, appointments, contents and condition private to the volunteers. Post no names, contacts or borrowing histories.

Use the six preparation hours for dates, the register, messages, checklists, return cards and a rehearsal. Physical checks happen in week 1’s permitted session. Cap printing and labels at £30, leaving £90 unspent. Incomplete items stay out of the trial; do not add repair or procurement work.

## Why this choice, and what follows

The notes record conflicting availability answers, failed handovers, unanswered requests and incomplete equipment. Seven carpet-cleaner requests and four projector requests justify prioritising them; three expressions of app interest establish little about adoption.

Continue only if completed loans meet residents’ intended uses, confirmations prove reliable, returns can be managed and recorded work fits 90 minutes weekly. Change the process if checks, messages or returns consume the allowance. Stop further lending if unresolved returns or incomplete equipment prevent dependable operation.

Record fulfilled requests, refusals and their reasons, wasted trips, return problems and volunteer minutes. Saturday workers may remain excluded; Thursday suitability is unknown. Four loans cannot establish demand across 48 households or justify expansion. If timing blocks interested residents, the next decision concerns feasible access, which this trial cannot create.
